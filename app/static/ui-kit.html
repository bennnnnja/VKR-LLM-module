UI Kit — витрина компонентов

Sandbox UI Kit OpenAPI

Три ванильных Web Component, готовых к встраиванию в любую страницу. Без сборщика, без зависимостей: подключаем <script src="/static/components/*.js"> — и тег работает.

<job-poller>

Опрашивает GET /jobs/{jobId} каждые N мс, рисует прогресс-бар, статус, актуальную модель и результат. Прекращает опрос при терминальном статусе и эмитит событие job-poller:done.

кнопка создаст задачу через /evaluate/task и вмонтирует ниже <job-poller>
Атрибуты
атрибуттипописание
job-iduuid (обяз.)идентификатор задачи
api-keystringесли не указан — берётся из localStorage["vkr_api_key"]
intervalint msинтервал опроса, default 1500, минимум 200
auto"false"не стартовать автоматически
События
событиеdetail
job-poller:updateJob (каждый успешный опрос)
job-poller:doneJob (терминальный статус)
HTML-вставка 
<script src="/static/components/job-poller.js"></script>
<job-poller
    job-id="9a7587ff-65cd-466a-825c-792817dac69c"
    api-key="..."
    interval="1500">
</job-poller>

<evaluate-form>

Форма «оценить ответ»: три textarea (задание, эталон, ответ студента), кнопка «Оценить» → отправка POST /evaluate/task. Внутри сама монтирует <job-poller> с полученным jobId.

Атрибуты
атрибуттипописание
api-keystringесли не указан — из localStorage["vkr_api_key"]
max-scorenumberверхняя граница шкалы, default 5
События
событиеdetail
evaluate-form:submitted{jobId}
evaluate-form:doneJob
HTML-вставка 
<script src="/static/components/job-poller.js"></script>
<script src="/static/components/evaluate-form.js"></script>
<evaluate-form max-score="10"></evaluate-form>

<recommendations-list>

Список рекомендаций, отсортированных по приоритету. Принимает массив через атрибут items (JSON) или сам грузит данные по job-id. Свойство .items = [...] работает программно.

Декларативно через items=
Из job-id (нажмите кнопку)
Атрибуты
атрибуттипописание
itemsJSONмассив {title, detail, priority}
job-iduuidесли задан — сам загрузит /jobs/{id}.result.items
api-keystringкак и у остальных, по умолчанию из localStorage
Свойство
имятипописание
.itemsArrayпрограммная установка списка
HTML-вставка 
<script src="/static/components/recommendations-list.js"></script>

<!-- 1. Декларативно -->
<recommendations-list items='[{"title":"...","detail":"...","priority":1}]'></recommendations-list>

<!-- 2. Из job-id -->
<recommendations-list job-id="..." api-key="..."></recommendations-list>

<!-- 3. Программно -->
<script>
document.querySelector("recommendations-list").items = [{title:"...", detail:"...", priority:1}];
</script>
