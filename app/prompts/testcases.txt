ОПИСАНИЕ ЗАДАНИЯ
{task_description}

ПАРАМЕТРЫ ГЕНЕРАЦИИ
Количество тест-кейсов: ровно {count}.
Язык, на котором будут писать студенты: {language}.
Включать граничные кейсы (type="edge"): {include_edge_cases}
Включать кейсы с невалидным вводом (type="negative"): {include_negative_cases}

ТРЕБОВАНИЯ К ТЕСТ-КЕЙСАМ
1. Каждый кейс — пара "входные данные → ожидаемый результат". Не пишите код реализации, только данные.
2. Каждый кейс имеет:
   - ordinal_number: порядковый номер от 1 до {count}, строго по возрастанию.
   - description: краткое (1 предложение) словесное описание того, что проверяет кейс.
   - input: входные данные как строка (что подаётся функции или в stdin).
   - expected_output: ожидаемый результат как строка.
   - type: один из "basic" | "edge" | "negative" (см. ниже).

ТИПЫ КЕЙСОВ
- "basic" — типичный корректный ввод. Должны присутствовать всегда.
- "edge" — граничный корректный ввод: пустой/минимальный/максимальный размер, нули, отрицательные, специальные значения. Включать ТОЛЬКО если include_edge_cases=true.
- "negative" — невалидный ввод, который функция должна обработать (неверный тип, выход за диапазон, мусор). Для таких кейсов в expected_output опишите ожидаемое поведение текстом: "raises ValueError", "возвращает None", "выводит 'Error'" и т.п. Включать ТОЛЬКО если include_negative_cases=true.

РАСПРЕДЕЛЕНИЕ ПО ТИПАМ
- Если оба флага false — все {count} кейсов type="basic".
- Если include_edge_cases=true и include_negative_cases=false — примерно 60% "basic" и 40% "edge".
- Если include_edge_cases=false и include_negative_cases=true — примерно 70% "basic" и 30% "negative".
- Если оба true — примерно 50% "basic", 30% "edge", 20% "negative".

ФОРМАТ ОТВЕТА
Верните строго один валидный JSON-объект следующей схемы. Никакого markdown, никакого текста до или после, никаких комментариев внутри JSON:

{{
  "cases": [
    {{
      "ordinal_number": 1,
      "description": "<словесное описание сценария>",
      "input": "<входные данные>",
      "expected_output": "<ожидаемый результат>",
      "type": "basic"
    }},
    ...
  ]
}}

Длина массива cases — ровно {count} элементов.
